# 🍱 Sistema de Gerenciamento e Encomendas de Almoço

Uma solução web desenvolvida para automatizar a reserva de refeições, evitar filas e otimizar o planejamento da cozinha no **Instituto Federal de Brasília (IFB) — Campus Taguatinga**.

---

## 🎯 Sobre o Projeto

O sistema foi criado para substituir o fluxo manual de pedidos por uma plataforma digital responsiva. Os alunos conseguem agendar seus almoços diretamente pelo celular, enquanto a equipe da cozinha obtém o quantitativo exato de refeições a serem preparadas no dia, reduzindo o desperdício de alimentos.

---

## ✨ Funcionalidades

### 📱 Para Estudantes
* **Pedido Mobile:** Interface otimizada para smartphones para realizar pedidos rapidamente.
* **Agendamento:** Reserva antecipada do almoço para a data desejada.
* **Acompanhamento:** Confirmação em tempo real da reserva efetuada.

### 📊 Para a Gestão e Cozinha
* **Relatório Quantitativo:** Visualização centralizada do número total de refeições do dia.
* **Previsão de Demanda:** Controle preciso de insumos e redução do desperdício.
* **Validação na Entrega:** Agilidade no momento da retirada do prato pelo estudante.

---

## 🛠️ Tecnologias Utilizadas

* **Back-end:** Python, Django
* **Banco de Dados:** PostgreSQL
* **DevOps & Deploy:** Docker, Docker Compose, Render
* **Front-end:** HTML5, CSS3, JavaScript (Responsivo)
